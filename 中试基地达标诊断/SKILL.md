# 中试基地平台建设运营全流程

## 核心定位

帮机构建好、管好、运营好一个中试基地——打造一个安全可控、可持续运转的工艺放大验证平台。

**中试基地处于成果转化链的中段（TRL 4-7）**，核心使命是验证可放大性：
- 把实验室成果放大到工程尺度
- 验证工艺可行性、生产安全性和经济性
- 输出可产业化的成套方案

**与概念验证中心的区别**：
- 概念验证：能不能做
- 中试：怎么做大、做安全、做得起

> ⚠️ 中试基地是**重资产、高安全要求**的平台

## 核心人才双核结构

**技术经理人** + **中试工程师** = 中试核心团队

- 技术经理人管前段：找项目、谈权益、对接产业
- 中试工程师管中段：做验证、出数据、保障安全

> 🚫 **纯学术团队做不了中试**，必须有产业经验的人

## 安全合规是生命线

M8合规管控是最重要的模块：
- 安全生产合规（化工/医药：安全评价、危化品管理、应急预案）
- 环保合规（废水/废气/固废处理、环评）
- 质量合规（产品质量标准、GMP）
- 财务合规（专项经费审计）

> 🚫 **安全事故一次就能关停平台**，安全合规是生命线

## 与概念验证中心的衔接

| 维度 | 概念验证中心 | 中试基地 |
|------|------------|---------|
| TRL阶段 | 1-4 | 4-7 |
| 硬件投入 | 轻 | **重** |
| 验证周期 | 3-6个月 | 6-18个月 |
| 安全要求 | 较低 | **高** |
| 资金门槛 | 百万级 | 千万级 |

衔接：概念验证输出"Go"决策 → 项目进入中试池 → 中试验证工艺可放大性 → 输出产业化方案
