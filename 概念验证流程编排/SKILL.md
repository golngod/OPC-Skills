# 概念验证流程编排

## 核心定位

帮项目设计最优的验证路径，用最小的成本、最短的时间、最可控的风险完成概念验证。

**与中试基地流程的区别**：
- 概念验证：轻量快速验证（3-12个月，多轮迭代）
- 中试流程：稳定可控放大（6-24个月，阶段性评审）

## Stage-Gate 体系

```
立项评审 → Stage1(原理验证) → Gate1 → Stage2(原型方案) → Gate2 
→ Stage3(原型开发) → Gate3 → Stage4(商业验证) → Gate4 → 进入中试
```

## Stage 定义

| Stage | 名称 | TRL范围 | 核心任务 | 典型时长 |
|-------|------|---------|---------|---------|
| Stage0 | 立项评审 | TRL 1 | 技术评估、立项决策 | 2-4周 |
| Stage1 | 原理验证 | TRL 2-3 | 原理可行性验证 | 2-4月 |
| Stage2 | 原型方案 | TRL 3-4 | 原型设计、方案评审 | 2-4月 |
| Stage3 | 原型开发 | TRL 4-5 | 原型开发、功能验证 | 2-6月 |
| Stage4 | 商业验证 | TRL 5-6 | 商业可行性验证 | 2-4月 |

## Gate 评审要点

| Gate | 评审要点 | 一票否决项 |
|------|---------|-----------|
| Gate0 | 技术可行性、商业潜力、资源就绪 | 无技术原理支撑、无IP保护 |
| Gate1 | 技术路线合理性、IP布局方案 | 侵权风险高、技术路线不可行 |
| Gate2 | 原型功能达标、成本可控 | 原型未达目标、无商业价值 |
| Gate3 | 技术验证成功、可演示 | 核心指标未达成 |
| Gate4 | 整体验证成功、进入中试价值 | 无中试价值、IP风险 |

## 三阶段设计

### 阶段1：TRL 1-2（原理验证）
- 投入：10-30万 | 周期：2-4月
- 验证科学原理是否成立
- 产出：原理验证报告、初步IP

### 阶段2：TRL 3-4（实验验证）
- 投入：30-100万 | 周期：4-8月
- 在实验室条件下验证技术
- 产出：实验室原型、技术参数

### 阶段3：TRL 4-6（小试/原型）
- 投入：100-300万 | 周期：6-12月
- 接近实际应用环境的验证
- 产出：可演示原型、小试工艺

## 流程编排5步法

1. **现状诊断**：评估TRL等级、识别已具备条件和缺失条件
2. **路径设计**：设计Stage-Gate路径、确定关键里程碑
3. **Gate评审设计**：制定评审标准、明确一票否决项
4. **风险预案**：识别关键风险、制定应对预案、备选路径
5. **资源规划**：编制资源需求计划、制定成本预算
