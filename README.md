# OPC-Skills

> 概念验证中心与中试基地运营管理技能库

## 概述

OPC-Skills 是一个专注于科技成果转化平台运营管理的技能（Skill）集合，包含概念验证中心（PVC）和中试基地（Pilot Base）两大核心场景的完整运营能力。

## 发布到ClawHub

### 方式一：使用ClawHub CLI（推荐）

```bash
# 检查登录状态
clawhub whoami

# 发布单个技能测试
clawhub publish ./OPC-Skills/concept-validation/

# 批量发布所有技能
cd OPC-Skills
for dir in */; do
  clawhub publish "./$dir"
done
```

### 方式二：手动上传

1. Fork 仓库到你的GitHub账号
2. 访问 https://clawhub.com/publish
3. 选择要发布的技能目录
4. 填写技能信息并发布

## 目录命名规范

本仓库遵循ClawHub命名规范：
- 目录名全小写
- 使用短横线（-）分隔单词
- 不使用中文目录名

原始中文目录名已通过 `slug-mapping.json` 映射为英文slug。

## SKILL.md 格式要求

所有Skill必须包含标准YAML frontmatter：

```yaml
---
name: skill-name
description: 技能描述
allowed-tools: []
---
```

## 许可协议

各技能采用独立许可，详见各技能目录下的SKILL.md文件。
